# Bảng màu tham chiếu idecal.vn

Trích từ HTML chủ website cung cấp ngày 14/11/2026, không phải kết quả truy cập website trực tiếp:

| Vai trò | Biến trong HTML nguồn | Màu |
| --- | --- | --- |
| Xanh da trời | primary | #17ABEB |
| Liên kết | secondary | #006EDC |
| Xanh đậm | basecolor | #082680 |
| Chữ trên nền xanh sáng | textonprimary | #031246 |
| Nút xanh đậm | button | #1D4C71 |
| Nền nhạt | textonbutton | #F3F4F8 |
| Nền trắng | contrastcolor | #FFFFFE |
| Chữ thân bài | màu dùng trong nội dung nguồn | #565D66 |

Nút chính dùng gradient primary → secondary như nguồn, chữ trắng. Không nhập các preset xanh lá mặc định của WordPress. Giữ nền footer xanh nhạt, bố cục hiện hành, ảnh và màu mẫu vật liệu. CSS ưu tiên: `src/styles/idecal-source-palette.css`.
